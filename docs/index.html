🖥️ TinyCore MultiBoot Factory

Создайте мультизагрузочную флешку с Tiny Core Linux за несколько кликов

🐍 Python 3.10+ 🖼️ PyQt6 🐧 x86 🖥️ x86_64 📱 aarch64

🚀 Возможности

💽 USB Detection

Автоопределение USB-флешек на Windows, Linux и macOS.

📦 Менеджер пакетов

Скачивание .tcz пакетов с зависимостями из репозиториев Tiny Core Linux.

🔧 GRUB Установка

Установка загрузчика GRUB для BIOS (i386-pc) и UEFI (x86_64-efi).

💾 Разметка диска

FAT32 (загрузочный) + exFAT (данные). Настраиваемый размер раздела.

📋 Логирование

Дата-штампованные логи в папке logs/ и в системе.

💾 Профили

Сохраняйте и загружайте настройки через JSON-профили.

📥 Установка

git clone https://github.com/falcga/TinyFactory.git
cd TinyFactory
pip install -r requirements.txt
python main.py

📖 Использование

  1. Вставьте USB-флешку и запустите приложение
  2. Выберите флешку из списка
  3. Отметьте пакеты для x86, x86_64 и/или aarch64
  4. Настройте размер boot-раздела и параметры GRUB
  5. Нажмите «Build USB Drive»
  6. Готово! Загружайтесь с флешки

🏗️ Структура флешки

/sda1 (FAT32, 200-4000 MB) — загрузочный раздел
├── boot/
│   ├── grub/grub.cfg
│   ├── vmlinuz-x86, core.gz-x86
│   ├── vmlinuz-x86_64, corepure64.gz
│   └── vmlinuz-aarch64, corearm64.gz

/sda2 (exFAT) — общий раздел
├── tce/
│   ├── x86/onboot.lst + optional/*.tcz
│   ├── x86_64/onboot.lst + optional/*.tcz
│   └── aarch64/onboot.lst + optional/*.tcz
├── home/
└── opt/

⚙️ Технологии

  • Язык: Python 3.10+
  • GUI: PyQt6 (Catppuccin Mocha theme)
  • Сеть: requests + ThreadPoolExecutor
  • Диски: diskpart (Win), parted (Linux), diskutil (macOS)
  • Репозитории: tinycorelinux.net/17.x
